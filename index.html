其他工具

任務腳本產生器 匯入 [{存檔名稱, 素材連結}]，勾選動作後下載 JSON。 使用說明 啟動方式、JSON 格式、各工具對照表。 素材資料夾 output 爬蟲／截圖結果，供筆記產生器選檔。 部署到 Vercel 把講義站上線（靜態）；本機產生器仍在本機跑。 從 JSON 到結果 任務執行流程與常見問題。

目錄結構

  • index.html ← 你在這裡（入口）
  • apps/ 前端：筆記產生器、腳本產生器
  • notes/ 已生成講義（含瀏覽頁）
  • output/ 素材文字／截圖
  • tools/ AutoHotkey 輔助腳本
  • docs/ 說明與 schema
  • *.py 本機伺服器／轉換／重渲腳本

建議雙擊根目錄 啟動工具.ahk，或執行 python note_generator_server.py 後用瀏覽器開本頁。

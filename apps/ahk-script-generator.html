任務腳本產生器

匯入你的格式：[{ "存檔名稱", "素材連結" }, …] → 再用 UI 設定要執行的動作 → 下載完整 JSON。

1. 匯入簡易 JSON 你的格式

支援陣列：每一筆只要 存檔名稱 + 素材連結。

2. 素材清單 0 筆

匯入後可微調；也可手動新增一筆。

3. 執行動作 依序執行，可含前置

順序固定：開網址 →（可選）點擊前置 → 等待 → 爬蟲／截圖…

建議用座標（最穩）：雙擊 取得滑鼠座標.ahk → 滑鼠移到「逐字稿」上 → 按 F8 → 把 X/Y 貼下方。
文字／class 自動找按鈕較不穩，座標失敗時可改用。

class 請直接貼 F12 Elements 看到的名稱，不要加點。
例：sc-jqnqvi-1 dyUpZz（中間空白＝兩個 class）
抓的是文字（不是 HTML）。勾「含底下全部」＝該 class 裡所有可見字；改勾「只取內文」會去掉按鈕／選單。

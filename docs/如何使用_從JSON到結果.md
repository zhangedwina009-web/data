# 怎麼用

## 啟動

雙擊 **`啟動工具.ahk`**（AutoHotkey v2）

1. 開「腳本產生器」→ 匯入素材 JSON → UI 勾執行 → 下載完整 JSON  
2. 開「執行任務」→ 選 JSON → **選瀏覽器** → 開始執行  
3. 到 `output` 拿檔（檔名＝存檔名稱）

## 瀏覽器

預設＝**只操控已開著的視窗**（AHK，**不會關閉／重開** Chrome）。

1. 先自己打開 Chrome 並登入  
2. `啟動工具.ahk` → 執行任務 → 選 JSON → 開始  
3. 腳本用網址列開分頁 →（可選）點「逐字稿」→ 再抓 class 到 `output`

## 前置點擊（用座標，最穩）

你之前的 `Y=-156` 是抓錯視窗（抓到工具本身）。請重抓：

1. 雙擊 `取得滑鼠座標.ahk`
2. **先開好 Chrome 課程頁**
3. 滑鼠移到 Chrome 裡的「逐字稿」上（不要點、也不要對著小工具視窗）
4. 按 **F8** → 應得到兩個**正數**，例如 `1019,642`
5. 填進產生器座標 X / Y → 下載 JSON → 執行

```json
{
  "動作": "點擊",
  "定位": "座標",
  "X": 1019,
  "Y": 642,
  "等待毫秒": 2000
}
```

若 F8 跳出「在視窗外／負數」，代表滑鼠沒對準瀏覽器內容。  
視窗大小或縮放變了要重抓。

## 爬蟲（抓 class 文字）

點完「逐字稿」後，腳本會開 **Console**，用你填的 class（例如 `sc-jqnqvi-1 dyUpZz`）複製**文字**存檔（不是 HTML）。

| 選項 | 意思 |
|------|------|
| `含底下全部: true` | class 裡所有可見字（含子元素） |
| `只取內文: true` | 去掉按鈕、連結、選單後，只留正文 |

```json
{ "動作": "爬蟲", "定位": "class", "值": "sc-jqnqvi-1 dyUpZz", "只取內文": true }
```

執行時不要搶鍵盤。內容載入慢就把點擊「等待毫秒」調到 `3000`。

## 教學筆記產生器（Ollama · 暗色 HTML）

把 `output` 裡的 txt 變成文圖並茂的響應式暗色筆記：

1. 本機先啟動 [Ollama](https://ollama.com/)，並 `ollama pull qwen2.5`（或其他模型）
2. `啟動工具.ahk` → **5. 教學筆記產生器**
3. 在頁面按「載入 output」勾選 txt，或貼上素材／填路徑
4. 選模型 → **生成筆記**（多檔用「批次生成勾選」）
5. 在「輸出資料夾」填要存的位置（預設 `notes`，可填 `notes/財稅` 或 `D:\我的筆記`）→ 生成  
6. 多檔／全選可選：**一檔一篇 HTML** 或 **合併一篇**  
7. AI 產出結構化內容後，**伺服器用 Bootstrap 直接渲染 HTML**（卡片／對照／表格／Chart／Mermaid），右側即時預覽  
8. 右上角可 **停止**；成品在輸出資料夾（`.html`）

網址：`http://127.0.0.1:8765/`（請重開伺服器並強制重新整理 Ctrl+F5）

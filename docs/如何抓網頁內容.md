# 多網址批次工具（爬蟲 / 截圖）

## 你要做的事

| 需求 | 動作選什麼 | class 要不要填 |
|------|------------|----------------|
| 抓文字存檔 | 爬蟲 | **要**（F12 複製 class） |
| 網頁截圖 | 截圖 | 可不填＝整頁；有填＝只截該區塊 |
| 文字＋截圖都要 | 兩者 | **要**（文字靠它；截圖也會優先截該區塊） |

---

## 最快用法（很多網址）

1. 雙擊 `啟動抓取工具.bat`
2. 在「一次貼很多網址」貼上，**每行一個**
3. 選預設動作：`爬蟲` / `截圖` / `兩者`
4. 若是爬蟲，填預設 class
5. 按 **加入清單** → **開始執行全部啟用項目**
6. 結果在 `output` 資料夾  
   - 爬蟲 → `.txt`  
   - 截圖 → `.png`

---

## 有些爬、有些截？

加入清單後，點表格某一列 → 下方改「動作」→ 按 **套用到選取列**。  
例如：

- 第 1～3 列：爬蟲  
- 第 4～5 列：截圖  
- 第 6 列：兩者  

然後一次按開始執行。

---

## class 怎麼找（只做一次）

1. 瀏覽器打開該網頁  
2. `F12` → `Ctrl + Shift + C`  
3. 點你要的區塊  
4. 複製 `class="xxx"` 裡的 `xxx`

---

## Excel 大量管理（可選）

1. 按「匯出 CSV 範本」  
2. 用 Excel 填：`enabled, action, url, selector, filename`  
3. 「匯入 CSV」再執行  

`action` 可填：`爬蟲`、`截圖`、`兩者`
